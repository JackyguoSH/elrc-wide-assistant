# ELRC 宽屏助手

为上海科技大学虚拟教学社区的课程回放页面提供宽屏布局、课程目录、课程时间线与语音文本复制。扩展只在 `https://elrc.shanghaitech.edu.cn/learn/videoreview/*` 课程详情页运行。

## 功能

- 扩大多画面播放器，隐藏网页叠加的个人水印；视频内容中已有的水印无法移除。
- 使用可收起的课程目录和横向时间线查看课件、知识要点并跳转播放位置。
- 在页面上复制已加载的语音转录文本；支持原站语音文本的搜索和语言控件。
- 扩展弹窗可调整宽屏布局、水印和面板设置。

## 安装

下载并解压本仓库，在 Chrome 打开 `chrome://extensions`，启用开发者模式，选择「加载未打包的扩展程序」，选择包含 `manifest.json` 的仓库文件夹。刷新课程回放页即可使用。请保留该文件夹，Chrome 会从这里加载扩展。

也可以把解压后的文件夹路径告诉支持电脑操作的 agent，并要求它按照 [AGENTS.md](AGENTS.md) 完成安装。agent 是否能执行取决于其电脑操作能力及适用的安全确认规则。

## 权限与数据

扩展读取课程回放页中已显示或加载的页面内容，以生成目录、时间线和语音文本；点击复制时将转录写入系统剪贴板。`storage` 用于保存本地设置，`clipboardWrite` 用于复制。源码未实现向第三方上传数据或远程分析。网页本身的网络行为不受本扩展控制。

## 维护说明

这是针对网站当前页面结构的非官方扩展，网站更新可能导致部分功能失效。播放器保留网站原有的多画面控制机制。修改扩展后在扩展管理页点击重新加载，再刷新课程页。
